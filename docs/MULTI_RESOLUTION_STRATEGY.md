# PalmView Multi-Resolution Data Strategy

## 核心理念：分辨率金字塔

棕榈油种植园监控需要**多尺度协同**，而不是单一分辨率。每个层级回答不同的业务问题。

```
┌─────────────────────────────────────────────────────┐
│  Level 1: 宏观监控 (10m Sentinel-2)                  │
│  "哪里有种植园？整体健康如何？有没有新的砍伐？"         │
│  覆盖: 整个柔佛州 / 全马来西亚                        │
│  频率: 每 5 天免费更新                                │
├─────────────────────────────────────────────────────┤
│  Level 2: 产区分析 (0.5-3m Planet/Pléiades)          │
│  "种植区块边界在哪？道路网络？哪些区块需要补种？"       │
│  覆盖: 特定种植园 / 10-50km²                         │
│  频率: 按需获取 / 每月                                │
├─────────────────────────────────────────────────────┤
│  Level 3: 单棵树管理 (0.02-0.1m 无人机)              │
│  "这棵树健康吗？产量预估？虫害检测？树龄？"            │
│  覆盖: 单个区块 / 1-5km²                             │
│  频率: 按需飞行                                       │
└─────────────────────────────────────────────────────┘
```

## Level 1: Sentinel-2 (10m) — 宏观之眼

### 不可替代的价值
| 能力 | 说明 | 高分辨率能替代？ |
|------|------|----------------|
| **全域覆盖** | 免费覆盖任意面积，柔佛 59,781 公顷全覆盖 | ❌ 成本太高 |
| **时序分析** | 5 天重访，可监控季节变化、生长周期 | ❌ 高分无法频繁获取 |
| **NDVI 健康监控** | 多光谱 (B2-B12)，远超 RGB | ❌ 无人机通常只有 RGB |
| **变化检测** | 毁林、新开发、火灾监测 | ❌ 需要历史归档 |
| **文本搜索入口** | RemoteCLIP 粗筛，快速定位目标区域 | 互补 |
| **SAR 融合** | Sentinel-1 雷达穿透云层 | ❌ 独有能力 |

### 在 PalmView 中的角色
```
用户搜索 "oil palm plantation near Kota Tinggi"
    ↓
Level 1 (S2 10m): RemoteCLIP 粗搜索 → 定位候选区域
    ↓
Level 2 (0.5m): 对候选区域加载高分影像 → 区块级分析
    ↓
Level 3 (无人机): 对特定区块 → 单棵树检测
```

**结论：10m 数据是入口和基础，不是终点。**

## Level 2: Planet / Pléiades (0.5-3m) — 产区分析

### 可实现的分析
- 种植区块边界自动提取
- 道路/河流网络识别
- 补种空缺检测（≥3m 间距的空位）
- 区块级树冠密度估算
- 建筑/设施识别

### 数据源
| 卫星 | 分辨率 | 光谱 | 重访 | 获取方式 |
|------|--------|------|------|----------|
| PlanetScope | 3m | 4-band (RGBNIR) | 每日 | API, 学术免费 |
| SkySat | 0.5m | 4-band | 按需 | API, 付费 |
| Pléiades | 0.5m | 4-band + PAN | 按需 | Airbus OneAtlas |
| WorldView-3 | 0.3m | 8-band + SWIR | 按需 | Maxar SecureWatch |
| SuperView-2 | 0.5m | 4-band + PAN | 按需 | 中国四维 |

## Level 3: 无人机 (0.02-0.1m) — 单棵树精度

### 可实现的分析
- 单棵棕榈树检测与计数
- 树冠直径测量 → 树龄估算
- 果实成熟度评估（RGB 颜色分析）
- 病虫害早期识别
- 产量预测模型

### 训练数据集（现有开源）
| 数据集 | 影像类型 | 分辨率 | 标注量 | 格式 |
|--------|---------|--------|--------|------|
| oilpalmuav (MDPI 2022) | 无人机 | 5cm | 56,614 树 | YOLO |
| Roboflow Palm Trees | 混合 | 多种 | 4,000+ 张 | YOLO/COCO |
| TS-CNN (Li et al.) | QuickBird 卫星 | 0.6m | 5,000 坐标 | CSV |
| CROPTD (South Malaysia) | Sentinel-2 + 标注 | 10m | 区域级 | GeoJSON |

## 时间分辨率的价值

| 时间尺度 | 分辨率 | 用途 |
|----------|--------|------|
| 每 5 天 | S2 10m | 健康趋势、异常预警 |
| 每月 | Planet 3m | 生长监控、补种跟踪 |
| 每季度 | 0.5m | 区块级盘点 |
| 按需 | 无人机 | 精准作业决策 |

## PalmView 数据流水线设计

```
┌──────────────────────────────────────────────────┐
│                Data Acquisition API               │
├──────────────┬──────────────┬────────────────────┤
│  GEE Service │ STAC Service │ Planet API (新增)  │
│  (S2, L8/9)  │ (MPC, E84)  │ (PlanetScope,      │
│              │ (Copernicus) │  SkySat)            │
├──────────────┴──────────────┴────────────────────┤
│              Tile Storage & Indexing              │
│  GeoTIFF → PNG tiles → CLIP embeddings → FAISS  │
├──────────────────────────────────────────────────┤
│              Analysis Pipeline                    │
│  Text Search → Dense CLIP → SAM2 → YOLO (树检测) │
└──────────────────────────────────────────────────┘
```

## 对 SD Guthrie 的价值主张

> "我们用免费的 Sentinel-2 覆盖你 59,781 公顷的全部种植园，
>  每 5 天自动检测异常区域。
>  对异常区域，自动调用高分影像做区块级分析。
>  对需要精准管理的区块，对接你的无人机数据做单棵树管理。"

这就是 **从太空到单棵树** 的完整解决方案。
