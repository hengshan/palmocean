## 一、核心交互哲学

### 🎯 从"地图浏览"升级为"空间操作系统"

一个优秀的 Browser-based GeoAI 平台必须满足五个原则：

| 原则 | 含义 |
|------|------|
| **Smart Default（默认即正确）** | 用户登录即看到最有价值的视图，无需配置 |
| **Data as Product（数据即资产）** | 每一份数据都经过标准化，可复用、可追溯 |
| **AI → Action（分析即动作）** | AI 分析结果直接驱动业务动作（下发任务、调度机器人）|
| **2D / 3D 无缝切换** | PalmView（2D）↔ PalmScene（3D）一键跳转，相机平滑飞行 |
| **Role-driven UI（角色驱动界面）** | 不同角色看到不同的界面和数据，降低认知负担 |

## 二、三个工作空间

产品分为 3 个独立 Workspace，而不是混在一起：

| Workspace | 主要用户 | 核心目的 |
|-----------|---------|---------|
| 🌍 **Operations Workspace**（PalmView）| 农场主 / 分析师 | 宏观监控 + AI 分析 |
| 🌲 **Field Workspace**（PalmScene）| 分析师 / 现场人员 | 微观 3D 验证 + 机器人联动 |
| 🧠 **Platform Console**（PalmOcean）| GIS 管理员 | 数据资产管理 + 模型管理 |

> **重要：** 平台 GIS 管理员是整个产品的地基。没有他们整理好的空间数据和三维模型，前两个工作空间看到的就是空壳。

## 三、三种角色操作主线

### 👨‍🌾 视角 1：农场主（业务决策者）

**核心诉求：** 不看过程，只看结果；不需要复杂工具，只需要看懂园区状况。

**主线逻辑：看报表 → 发现问题 → 下达指令（闭环）**

| 操作主线 | 分支路径 | 交互设计要点 |
|---------|---------|------------|
| 园区总览 | 默认进入仪表盘视图 | 地图自动缩放到全部园区，右侧显示关键指标卡片（总面积、总株数、平均健康分）|
| 健康度监控 | 点击异常区域 → 查看详情 | NDVI 图层默认开启，红色区域可点击，弹出"疑似病害，建议排查"提示 |
| 产量预估 | 选择林区 → 查看预估报表 | 不展示 AI 分割过程，直接显示"预计成熟果实 XX 吨" |
| 任务下发 | 勾选问题区域 → 指派任务 | 简单表单：选择人员、填写备注，无需接触任何技术参数 |

---

### 👨‍💻 视角 2：现场人员 / 分析师（PalmView + PalmScene 操作者）

**核心诉求：** 用 AI 工具分析具体问题，查看三维实景，为决策提供依据。

**主线逻辑：加载数据 → 执行分析 → 验证结果 → 输出任务**

| 操作主线 | 分支路径 | 交互设计要点 |
|---------|---------|------------|
| 数据加载与探查 | 从 Catalog 加载最新飞巡数据 → 叠加比对 | 可以开关图层、调整透明度、查看属性表 |
| AI 分析执行 | 框选区域 → 选择分析类型 → 查看结果 | 分析过程中显示进度条，完成后自动渲染结果图层 |
| 三维验证 | 双击可疑树木 → 切换到 PalmScene | 相机平滑过渡，3D 场景中高亮该树木，可旋转查看 |
| 现场任务执行 | 在 3D 中标记问题点 → 同步到 APP | 技术人员可为采摘机器人设置路径点 |

---

### 🧠 视角 3：平台 GIS 管理员（数据管家）

**核心诉求：** 保证数据的正确性、完整性、可用性；维护三维模型的精度和性能；为用户准备好"开箱即用"的数据环境。

**主线逻辑：数据接入 → 清洗处理 → 发布服务 → 监控维护**

| 操作主线 | 分支路径 | 交互设计要点 |
|---------|---------|------------|
| 数据接入与校验 | 上传原始数据 → 坐标系校验 → 属性字段映射 | 显示原始文件名、坐标系统警告、字段类型检测 |
| 数据清洗与处理 | 编辑矢量边界 → 合并/分割地块 → 修正错误标注 | 提供 GIS 编辑工具（节点编辑、属性修改）|
| AI 模型配置 | 选择训练区域 → 触发模型重训 → 评估精度 | 显示精度指标（mAP, IoU），可调整训练参数 |
| 三维场景管理 | 导入新的三维模型 → LOD 设置 → 光照环境配置 | 性能监控面板（FPS, 三角面数）|
| 用户权限配置 | 分配数据可见范围 → 设置操作权限 | 谁可以看到哪些地块？谁可以编辑？ |

## 四、技术人员专用操作设计（Platform Console 详解）

### 4.1 管理控制台界面布局

```
┌─────────────────────────────────────────────────────────────┐
│ 导航栏：数据管理 | 模型管理 | 三维资产 | 用户权限 | 系统监控 │
├───────────────────┬─────────────────────────────────────────┤
│                   │                                         │
│ 数据目录树        │ 数据预览窗口                             │
│ ├─ 原始数据       │ [地图 / 表格 / 三维场景]                │
│ ├─ 处理中         │                                         │
│ ├─ 已发布         │                                         │
│ └─ 归档           │                                         │
│                   │                                         │
│ ▸ 坐标系检测      │                                         │
│ ▸ 字段映射        │                                         │
│ ▸ 质量报告        │                                         │
│                   │                                         │
├───────────────────┼─────────────────────────────────────────┤
│                   │                                         │
│ 属性编辑面板      │ 日志 / 控制台输出                        │
│ 节点坐标: xxxxx   │ [实时显示处理进度、错误信息]             │
│ 字段值: xxxxx     │                                         │
│                   │ [INFO]  数据发布成功                    │
│                   │ [WARN]  坐标系缺失，已自动修正           │
└───────────────────┴─────────────────────────────────────────┘
```

### 4.2 主线 A：数据全生命周期管理

**① 数据接入阶段**

操作：点击"上传数据" → 选择文件（Shapefile / GeoJSON / GeoTIFF / LAZ 点云）

向导式对话框四步流程：
1. **文件校验** — 大小、格式、完整性检查
2. **坐标系检测** — 自动识别 / 手动指定
3. **字段映射** — 原始字段 → 平台标准字段（如 `tree_height` → `height_m`）
4. **数据预览** — 快速渲染样本确认

**② 数据处理阶段**

右键数据 → 选择处理类型：

| 类型 | 操作 |
|------|------|
| 矢量编辑 | 合并相邻地块、修正拓扑错误（自相交多边形等）|
| 栅格处理 | 裁剪、重采样、波段计算（如计算 NDVI）|
| 点云处理 | 滤波、分类、生成 DEM/DSM |

**③ 数据发布阶段**

处理完成 → "发布服务"界面：
- 选择服务类型（矢量瓦片 / 动态图层 / 3D Tiles）
- 设置缓存策略
- 预览发布效果
- 一键复制调用链接（供 PalmView / PalmScene 使用）

### 4.3 主线 B：三维资产管理

> 这是 PalmScene 能够运行的基础

**① 模型导入与优化**

上传模型（FBX / GLTF / OBJ）后自动处理：
- 自动转换 → GLTF/GLB 格式
- LOD 自动生成：LOD0（高模）/ LOD1（中模）/ LOD2（低模）
- 纹理压缩（根据目标设备选择压缩率）

**② 场景组装**

新建场景 → 拖拽模型到场景中：
- 场景树结构：根节点 → 地块 → 单株棕榈树
- 属性面板：位置坐标、旋转角度、缩放比例
- 光照配置：太阳角度、环境光强度

**③ 性能调优**

"性能分析"面板：
- 实时 FPS 监控
- 三角面计数 / 绘制调用次数
- 系统建议："当前场景面数过高，建议启用 LOD 切换"

### 4.4 主线 C：系统监控与运维

**服务健康度监控**
- 各服务运行状态（正常 / 高负载 / 异常）
- API 调用次数统计
- 存储空间使用情况

**日志查看**
- 分级显示（INFO / WARNING / ERROR）
- 按时间 / 用户 / 模块筛选
- 错误详情追溯（点击错误查看堆栈信息）

**用户行为审计**
- 谁在什么时间做了什么操作？
- 哪些数据被频繁访问？
- 用于优化缓存策略和数据结构

## 五、三个视角的协同关系

```
┌─────────────────────────────────────────────────────────┐
│              🧠 平台 GIS 管理员（数据管家）               │
│  ─────────────────────────────────────────────────────  │
│  核心职责：让数据正确、可用、高效                         │
│  输出：清洗后的数据集 + 优化后的 3D 模型 + 配置好的服务   │
└────────────────────┬────────────────────────────────────┘
                     │ 提供可靠数据
                     ↓
┌─────────────────────────────────────────────────────────┐
│           👨‍💻 现场人员 / 分析师（PalmView/PalmScene 用户）│
│  ─────────────────────────────────────────────────────  │
│  核心职责：用数据做分析，发现问题                         │
│  输出：分析报告 + 标记的问题点 + 任务指令                │
└────────────────────┬────────────────────────────────────┘
                     │ 提供决策依据
                     ↓
┌─────────────────────────────────────────────────────────┐
│                  👨‍🌾 农场主（业务决策者）                  │
│  ─────────────────────────────────────────────────────  │
│  核心职责：看报表，下决策，派任务                         │
│  输出：经营指令 + 资源调度方案                            │
└─────────────────────────────────────────────────────────┘
```

## 六、三角色主线总结

```
👨‍🌾 农场主主线：  看总览 → 发现问题 → 查看结果 → 下达任务

👨‍💻 分析师主线：  加载数据 → 执行 AI → 进入 3D → 输出报告

🧠 GIS管理员主线：接入数据 → 清洗标准化 → 发布服务 → 监控运行
```
