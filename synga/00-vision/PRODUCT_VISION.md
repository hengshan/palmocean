## 🌍 PalmView — 宏观遥感分析驾驶舱

**定位：** 2D/2.5D · 卫星 + 无人机图像的 AI 分析与决策平台

**技术栈：** Kepler.gl fork + GeoAI Tab + Redux + Deck.gl + MapboxGL

**核心能力：**
- 多源遥感数据接入（Sentinel-2、Landsat、无人机航片、COG）
- AOI 绘制 → AI 推理 → 结果叠加地图（一键操作）
- 棕榈树检测、建筑物分割、水体提取等语义分析
- 自然语言指令驱动 GIS 分析（RemoteCLIP）
- 时序对比分析（种植面积变化、健康度趋势）

**用户场景：** 区域经理/决策者在大屏查看整个种植园的宏观态势，下达决策指令

---

## 🌲 PalmScene — 3D 地理空间数字孪生可视化

**定位：** 3D · 种植园现实世界的立体可视化镜像，不是独立产品，是 PalmOcean 数据的 3D 渲染层

**技术栈：**
- **主引擎：CesiumJS** — 真实 WGS84 地理坐标、地形、3D Tiles、点云
- **辅助引擎：Three.js + @react-three/fiber** — 高度定制的 3D 元素（机器人、仪表、特效）

**为什么 CesiumJS 是主引擎：**
- 真实大地坐标系，棕榈树点云/地形可精确落位
- 3D Tiles 标准：大规模点云、地形、建筑物资产化
- 原生支持时序动画（机器人路径回放）
- Three.js 做无法用 CesiumJS 实现的高度定制部分

**核心能力：**
- 棕榈树点云 / 地形 → 3D Tiles 资产化渲染
- 种植园地块 3D 边界 + 健康度热力可视化
- HarvestBot 机器人实时位置 + 状态动画
- 点击地图 → PalmScene 联动（从 2D 下钻到 3D）

**用户场景：** 农场技术员查看单个地块的 3D 精细状态，追踪机器人作业

## 🌊 PalmOcean — 数字孪生数据中台（后端核心）

**定位：** 后端数据层，不是展示平台
PalmView 和 PalmScene 都是 PalmOcean 的"窗口"。没有 PalmOcean，它们都是空壳。

> **Ocean 的隐喻：深层、流动、包含一切**
> 物理种植园每时每刻发生的事，都在这片海洋里留下痕迹

**技术栈：** FastAPI + TimescaleDB（时序扩展）+ PostgreSQL/PostGIS + MQTT + WebSocket

**四大核心能力：**

### 1. 实时状态同步（物理 → 数字镜像）
```
IoT 传感器 → MQTT broker → PalmOcean 状态引擎 → 数字孪生状态更新
无人机/机器人 → WebSocket → 实时位置/任务状态同步
```

### 2. 时序数据存储与分析
- 每棵树的历史数据（NDVI、土壤湿度、健康分、采收记录）
- 每台设备的轨迹与操作日志
- 气象数据时序（温度、降雨、光照）

### 3. 数字孪生状态机
- 每个物理实体（树 / 机器人 / 地块）都有一个数字状态对象
- 状态变化触发事件流（健康预警、任务完成、异常告警）

### 4. 统一数据 API
- REST API — PalmView/PalmScene 查询历史数据
- WebSocket — 实时状态推送（地图上的树实时变色）
- 开放 API — 第三方系统集成（ERP、供应链）

**用户场景：** 对用户透明，是整个系统的"心跳"

## 🎯 设计原则

1. **极简操作，深度智能** — 用户只需"画框 + 点击"，AI 完成复杂分析
2. **数据飞轮** — 每次操作产生标注数据，反哺模型迭代
3. **空天地一体** — 卫星(宏观) → 无人机(中观) → 机器人(微观) 无缝联通
4. **PalmOcean 优先** — 新功能先建数据层，再建展示层
5. **可解释 AI** — 每个推理结果都有 confidence 和可视化解释
6. **离线优先** — 农场网络不稳定，核心功能必须离线可用
